# Task 2 — Length scores

**Status:** done for every aya and every phrase. Results and numbers:
[02-scores-analysis.md](02-scores-analysis.md).

## Goal

Measure every phrase in two ways, so that later divisions can be balanced for both
audiences:

1. **Recitation score**: how long the phrase takes to recite, as phonemes weighted by
   Hafs madd lengths.
2. **Typesetting score**: how much room the phrase takes in print, as its width set in
   the DigitalKhatt font on one line.

## Data

| file | content |
|------|---------|
| `data/scores/recitation_ayat.tsv` | per aya: written letters, silent, plain, madd 2/4/6 counts, score |
| `data/scores/typesetting_ayat.tsv` | per aya: words, width in em and px |
| `data/scores/phrases.tsv` | per phrase: ayat, words, letters, recitation, typeset em and px |
| `data/scores/basmala_*.tsv` | the basmala, scored once (it is not part of any aya here) |
| `data/scores/typesetting_constants.tsv` | space width and the px font size |
| `data/scores/analysis.json` | every number in the analysis report |

`tajzee/scores.py` reads these files. It scores any range of ayat, with or without the
basmala of surahs opening inside it. Later tasks need only this module, not the external
projects.

## 1. Recitation score

Source of truth: [tajweed-embeddings](https://github.com/tarekeldeeb/tajweed-embeddings),
one vector per letter with tajweed flags from the
[cpfair/quran-tajweed](https://github.com/cpfair/quran-tajweed) decision trees (Hafs).

- Each aya is recited on its own: it is begun (ibtidāʾ) at its first word and stopped
  (waqf) on its last, with continuous recitation (waṣl) inside it. The embedder's start
  and stop variants supply what changes at those points. Hamzat al-waṣl is voiced at the
  start, and the stop brings madd ʿāriḍ, tāʾ marbūṭa read as hāʾ, and tanwīn fatḥ read as alif.
- Each letter counts:

  | letter | count |
  |--------|-------|
  | `madd_2` (ṭabīʿī, and the forms the embedder maps to it) | 2 |
  | `madd_munfasil`, `madd_muttasil` (Hafs via al-Shāṭibiyya, tawassuṭ) | 4 |
  | `madd_246` (ʿāriḍ lil-sukūn at a stop; 2, 4 or 6 allowed) | 4 |
  | `madd_6` (lāzim) | 6 |
  | not pronounced: `silent`, `hamzat_wasl` mid-aya, `lam_shamsiyyah` | 0 |
  | every other letter | 1 |

  Several madd flags on one letter: the longest wins. Shadda, ghunnah and qalqalah are
  not weighted, as asked ("other phonemes count 1").
- The tajweed rules were generated by the embedder from `data/source/quran-uthmani.txt`,
  so the letters match this project's text exactly. That file has no pause marks
  (ۖ ۗ ۚ …). They do not change any madd in waṣl, and each aya is scored with a stop at its
  own end only, so they do not affect the score.
- Known limit inherited from the source: the lām of the divine name after hamzat al-waṣl
  is not flagged, so it counts 1.

Run: `TAJWEED_EMBEDDINGS=../tajweed-embeddings python scripts/score_recitation.py`.
The first run takes about five minutes while the embedder generates its rule file; the
scoring itself takes about 15 seconds.

## 2. Typesetting score

Source of truth: [quran-nazm](https://github.com/tarekeldeeb/quran-nazm). Its `Text`
class is used unchanged. It reads the 1441H Madina text from
[quran-madina-html](https://github.com/tarekeldeeb/quran-madina-html) v2.0 and shapes it
with HarfBuzz in the patched DigitalKhatt "QMH New Madina" font.

- Each word is shaped unstretched (no kashida, no shrink features), exactly as
  Quran-Nazm's line breaker measures it.
- Words are joined by one normal space (0.1 em). The ayah-number marker is glued to the
  preceding word with a 1.5× space.
- A phrase on one line: its ayat side by side, one normal space between ayat.
- Units: em, and px at 24 px font size (quran-madina-html's reference size). Pixels scale
  linearly with font size, so no comparison depends on it.
- The basmala is a header line in the Mushaf, not part of aya 1; its width is stored
  separately. Surah title lines are not measured.

Run, with quran-nazm's fonts prepared (`python scripts/00_prepare.py` in quran-nazm):

```sh
QURAN_NAZM=../quran-nazm QMH=../quran-madina-html NAZM_WORK=../quran-nazm/build \
    python scripts/score_typesetting.py
```

Check: the whole text measures 139,267 em, which is 9,021 lines of the 1441H print's
15.44 em width, or about 601 pages of 15 lines. Surah header lines bring that to the
print's 604.

## Decisions to revisit

- Madd ʿāriḍ is taken at 4 and the two Hafs madd farʿī at 4. Any choice is one constant in
  `scripts/score_recitation.py`.
- Stops are placed at every aya end. A reciter who joins ayat changes little, a few
  harakat per aya.
- Surah openings (basmala, title line) are fixed costs kept outside the per-aya scores.
  Task 3 decides how to weigh them.
